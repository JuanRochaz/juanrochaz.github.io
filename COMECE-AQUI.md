# Como abrir no Claude Code

1. Descompacte esta pasta (ex.: Documentos/portfolio-juan).
2. Abra o terminal dentro dela e rode: `claude`
   (ou, no app do Claude, abra o Claude Code apontando para esta pasta)
3. Primeira mensagem sugerida:

> Leia o CLAUDE.md e o design em design/referencia-design.html.
> Monte a estrutura do site (index.html, css/style.css, js/main.js, data/projetos.js)
> seguindo a skill design-system-portfolio. Vá explicando o que fez.

O Claude Code carrega o CLAUDE.md e as skills da pasta .claude/skills sozinho.
