Site Maps – gerador de sites a partir do Google Maps

Ferramenta que transforma o link de uma empresa no Google Maps em um site completo, pronto para publicar. Criada para a prospecção da JR Dev.

  • Node.js
  • JavaScript
  • HTML
  • CSS
  • Google Places API
  • Netlify
  • Claude Code
  • Automação
Ver código (abre em nova aba)

o desafio

Do link do Maps ao site no ar.

Muitas empresas locais têm boas avaliações no Google, mas não têm site. O Site Maps automatiza a criação de uma demonstração personalizada para apresentar a esses negócios:

  1. Coleta: com o link do Google Maps, busca nome, endereço, telefone, horário, nota, avaliações e fotos pela Google Places API (New).
  2. Nicho: identifica o tipo de negócio e escolhe um dos 5 modelos (barbearia, oficina, clínica, restaurante e geral, para escritórios e contabilidade).
  3. Textos: o Claude escreve textos personalizados para a empresa, sem inventar informações.
  4. Geração: monta um site responsivo em um único arquivo HTML, com botão de WhatsApp, avaliações, horários e mapa.
  5. Publicação: deploy automático na Netlify e mensagem de abordagem pronta para o WhatsApp.

Tudo é executado com um único comando no Claude Code: /site-maps <link do Maps>.

por dentro

Destaques técnicos.

  • Node.js (ES Modules) sem dependências externas, usando fetch nativo
  • Integração com a Google Places API (New): Text Search + Place Details + Photos
  • Sistema de templates com placeholders e temas por nicho (CSS custom properties)
  • Detecção automática de celular → link do WhatsApp; telefone fixo → link de ligação
  • Modo demonstração (faixa + noindex) e modo final (--final)
  • Automação com comando personalizado do Claude Code + Netlify CLI
